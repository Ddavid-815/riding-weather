🚴 라이딩 적합도 기준

🟢 좋음: 강수량 1mm 이하, 최고 14~26°C, 최저 5°C 이상
🟡 주의: 다소 춥거나 덥거나 약한 강수
🔴 비추천: 일강수량 8mm 이상, 영하, 폭염, 뇌우

참고용 단순 분류입니다. 바람과 시간대별 강수, 노면 상태는 라이딩 적합도 판정에 반영하지 않습니다. ECMWF 원본은 예보 후반부에 3~6시간 간격으로 제공되며 Open-Meteo에서 시간 보간해 제공할 수 있습니다.

출처: Open-Meteo ECMWF IFS 모델 지정 API. 검색 지역은 Open-Meteo 지명 검색을 사용하며 일부 국내 주요 지역은 대표 좌표를 적용합니다. 예보는 해당 지역 중심 좌표 기준으로 제공되며 다른 예보 모델의 값을 혼합하지 않습니다. 풍향 명칭은 바람이 불어오는 방향(북풍 = 북쪽에서 불어옴), 화살표는 실제 바람이 이동하는 방향(북풍 ↓)을 가리킵니다. 풍속은 지상 10m의 일 최대값입니다. 인터넷 연결이 필요합니다. 위치 권한을 허용하면 해당 GPS 좌표가 지명 확인용 BigDataCloud API에도 전송됩니다. 위치 권한을 거부하면 서울 예보를 표시하며, 지명 확인에 실패한 경우에는 좌표를 표시합니다. iPhone의 파일 미리보기 환경에서는 외부 API 요청이 제한될 수 있습니다.
