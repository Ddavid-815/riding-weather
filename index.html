일강수량 · mm

날짜별 일강수량을 10칸 단색 눈금으로 비교합니다. 강수량 숫자는 막대 위에 고정 표시되며 채워진 칸 수가 많을수록 강수량이 많습니다.

1050

모든 날짜에 동일한 10칸 눈금을 사용합니다. 강수량이 증가할수록 아래 칸부터 채워지며, 0mm는 빈칸 10개로 표시합니다. 모바일에서는 좌우로 밀어 확인하세요.

1주차 · D+0~D+6

2주차 · D+7~D+13

🚴 라이딩 적합도 기준

🟢 좋음: 강수량 1mm 이하, 최고 14~26°C, 최저 5°C 이상
🟡 주의: 다소 춥거나 덥거나 약한 강수
🔴 비추천: 일강수량 8mm 이상, 영하, 폭염, 뇌우

참고용 단순 분류입니다. 주풍향과 일 최대풍속(지상 10m)은 별도 표시하며, 라이딩 적합도 판정에는 반영하지 않습니다. 시간대별 바람·강수와 노면 상태도 반영하지 않습니다.

출처: Open-Meteo ECMWF IFS 모델 지정 API. 검색 지역은 Open-Meteo 지명 검색을 사용하며 일부 국내 주요 지역은 대표 좌표를 적용합니다. 예보는 해당 지역 중심 좌표 기준으로 제공되며 다른 예보 모델의 값을 혼합하지 않습니다. 풍향 명칭은 바람이 불어오는 방향(북풍 = 북쪽에서 불어옴), 화살표는 실제 바람이 이동하는 방향(북풍 ↓)을 가리킵니다. 풍속은 지상 10m의 일 최대값입니다. 인터넷 연결이 필요합니다. iPhone의 파일 미리보기 환경에서는 외부 API 요청이 제한될 수 있습니다.
